通知文：「ログインの有効期限が切れたため、ログアウトします。再度ログインしてください。」opaque tokenの期限切れは次回refresh時に判定し、期限到達を監視するtimerやpollingは追加しません。

変更内容と理由

digest一致rowを検索
→
revoked / expiryを判定
→
期限切れだけ専用401
→
session clear・通知1回

Backendはopaque tokenのdigestからsession rowを取得します。rowなし・失効済み・rotation競合は既存の INVALID_REFRESH_TOKEN を返し、未失効rowの expiresAt <= now の場合だけ REFRESH_TOKEN_EXPIRED を返します。期限内のrotation条件は維持します。

Frontendはrefresh attemptとsession generationに失敗理由を結び付け、同じ失敗のcleanupと期限切れ通知を一度に抑えます。logout requestは開始時のrefresh tokenとgenerationを捕捉し、遅れて完了した古いrefresh/logoutが新しいsessionを上書き・消去しないようにします。期限切れ通知はRouter内・Routes外のAlertProviderから表示し、sessionQuery errorとの重複を抑止します。network/5xx等の従来のclear挙動は維持し、期限切れ通知は出しません。
