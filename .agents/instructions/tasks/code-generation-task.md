# コード生成タスク

共通契約は[AGENTS-DETAILS.md](../AGENTS-DETAILS.md)を参照する。

## 目的

承認済み計画と計画書読み取り結果に従い、現在Phaseの差分を最小範囲で実装する。

## 担当・権限

規模に応じLunaまたはTerraを指定する。書き込み担当は同時に1人だけ。計画範囲と最終品質判定はメインが保持し、他者の未コミット差分を保護する。

## 開始条件／入力

チャット上の本人承認、整合確認済みの人間向けHTMLとAI向けMarkdown、計画書読み取り結果、既存コード、必要なUIモックと再現条件。

## 手順

1. branch、HEAD、差分と計画対象を確認し、他者の差分を保護する。
2. 現在Phaseの対象/対象外、受入条件、共通コード規則を確認する。
3. 計画対象だけを実装し、必要なテストを追加・更新する。
4. DB Schema変更は承認済み計画にある場合だけmigrationを作成し、SQL確認と適用を行う。
5. 結果と完了項目をAI向け計画書へ反映し、変更理由、検証状況、未解決事項を記録する。

## 禁止事項

- 計画外のDB、migration、依存、API、権限、仕様、設定変更
- 他者の変更を巻き戻すこと、公開操作、品質PASSの最終判定
- 秘密情報、debug log、検査回避コードの追加

## 成果物／完了条件

対象Phaseの差分、必要なテストとmigration、実行結果、未実行検証、未解決事項を記録し、技術QA・仕様QAへ渡せる状態。

## 失敗時／差戻し

verifyまたは受入条件が失敗したら原因を修正し再検証する。計画外変更が必要ならREPLANで停止する。QA FAILは根拠に沿って修正する。

## 次タスクへの引き継ぎ

変更ファイルと理由、テスト/migration、検証コマンドと結果、未実行検証、未解決事項を[テスト・QAタスク](test-task.md)へ渡す。
